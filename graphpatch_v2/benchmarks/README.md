`vul4j_dataset.csv` (used by `vul4j_bench.py`) is a copy of the Vul4J dataset file
(https://github.com/tuhh-softsec/vul4j/blob/main/dataset/vul4j_dataset.csv, fetched 2026-10-17),
licensed CC-BY-4.0. Cite: Bui, Scandariato, Ferreyra, "Vul4J: A Dataset of Reproducible Java
Vulnerabilities Geared Towards the Study of Program Repair Techniques", MSR 2022.
GraphPatch uses the 79 entries that have PoV tests (VUL4J-1 to VUL4J-79).
